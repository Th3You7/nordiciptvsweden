Running IPTV on a computer is the quickest way to try a service: the machine is already there and no new hardware is needed. This guide covers what the computer needs, how to install and run the player, how to get the picture onto the television, and what usually goes wrong.

One decision is new this year and affects a lot of households in Sweden: Windows 10 no longer receives ordinary updates, so if an old laptop is to become your TV machine, that has to be settled first. *Information checked 2 November 2026.*

## What the computer actually needs

Less than most people expect. Streamed television is decoded in the graphics chip rather than the processor, so a machine from the last eight years is plenty — a modest laptop included. What decides the experience is the connection, a spare HDMI output if the television is involved, and an operating system that still receives security updates.

| This matters | This matters less |
|---|---|
| A steady connection, ideally over Ethernet | Processor clock speed |
| An operating system still getting security updates | RAM beyond 8 GB |
| A spare HDMI output if the TV is involved | A gaming graphics card |
| Getting the player app from the right source | How old the machine looks |

We recommend at least 15 Mbps for HD and 25 Mbps for 4K. How to measure what you actually have at home is covered in [our guide to internet TV](/en/blog/basta-internet-tv).

## Windows 10: the decision to settle first

This is the year's most important point for anyone reusing an older machine. Support for Windows 10 ended on 14 October 2025, and Microsoft no longer supplies free updates or technical help. The computer still works, but the operating system itself no longer receives the ordinary security fixes.

There is a way forward without replacing the machine. Private users can enrol in **Extended Security Updates (ESU)**, and [Microsoft's own page](https://www.microsoft.com/en-us/windows/extended-security-updates) states that "you can enroll in ESU any time until the program ends on October 12, 2027". Three details are worth knowing:

- **It requires version 22H2**, in the Home, Professional, Pro Education or Workstations edition.
- **One licence covers up to ten devices** tied to the same Microsoft account.
- **It is security updates only.** Microsoft states plainly that ESU provides no feature or product improvements and no technical support.

One correction worth making, because it is still circulating: many articles give **13 October 2026** as the end date. That was the consumer programme's original date before it was extended, so it has already passed without the programme ending. Check the date at Microsoft before planning around it.

## Player app or browser — what the difference is

Both work, and they solve different problems. A **player app** is built for linear television: it handles the channel list, the TV guide and catch-up in an interface made for hundreds of channels, and it changes channel faster than a browser tab. The **browser** is convenient as a fallback and for play services you already use.

There is also a technical difference worth naming without overstating it: how a service delivers picture inside a browser depends on that browser's own protection mechanisms, and those are not identical across browsers or machines. Which route looks best on your computer is therefore an empirical question rather than a matter of principle. Test both during a trial instead of trusting a table.

## How to install and run IPTV on a computer

Five steps take you from a bare machine to a channel list that plays. The order is not arbitrary: network first, then the app, then the credentials, and the television last — so you know where the fault sits if something does not work. Allow about a quarter of an hour.

1. **Check the computer and its operating system.** Find out which system you are running and whether it still gets security updates. If it is Windows 10, read the section above first.
2. **Plug in an Ethernet cable if you can.** A cable to the router gives a steadier stream than Wi-Fi. If you cannot, use the 5 GHz band and place the router in the open rather than inside a cupboard.
3. **Install a player app.** Get it from the developer's own site or your operating system's app store. Avoid download links posted in forums and comment threads — that is where fake builds spread.
4. **Enter your credentials.** Fill in the server address, username and password, or the M3U link you were sent. Save, and let the player fetch the channel list and the TV guide.
5. **Test before connecting the TV.** Start a live channel and a film and let them run a few minutes. If it works on the computer, the rest is just a cable.

## Getting the picture from the computer to the TV

An HDMI cable from the computer's output to a spare input on the television is almost always enough. If the machine only has USB-C, an adapter does the same job. Select the right input on the TV remote and set the computer to show its picture on the external screen.

Two things commonly surprise people:

- **Audio travels over HDMI**, but not always automatically. If you get picture and no sound, change the playback device in the computer's sound settings.
- **The resolution is set by the computer**, not by the television. If the machine is set lower than the TV can show, the picture is softer than it needs to be.

If you would rather not keep a computer by the television, a box is the usual answer — and whether one is needed at all is covered in [our guide to choosing an IPTV box](/en/blog/iptv-box-malmo).

## Four common faults, and what causes them

Most trouble on a computer sits in the network or the settings rather than the service. Four causes cover nearly everything, all four take a few minutes to test before you contact anybody, and the table below pairs each symptom with its likely cause.

| Symptom | Most likely cause | Try this |
|---|---|---|
| Picture stutters in the evening | Wi-Fi and network load | Ethernet, or 5 GHz instead of 2.4 GHz |
| Picture but no sound | wrong playback device after HDMI | change the audio output in system settings |
| Channel list is empty | wrong server address or M3U link | check the details character by character |
| Everything buffers, play services too | the connection, not the service | measure over cable and compare with your plan |

## Computer or box at the television — which suits whom

The computer wins on already existing and costing nothing extra to try with. A box wins on being quieter, drawing less power, starting faster and not needing to be used for anything else at the same time. So the choice turns less on technology than on where the computer sits and what else it is for.

A sensible order: test on the computer first, because it costs nothing. If that shows the service works and you want it permanently at the television, buy hardware then — not before.
